# Быстрый запуск

- Windows: дважды щёлкните `start-windows.bat`.
- macOS: щёлкните `start-mac.command` правой кнопкой и выберите «Открыть».
- Linux: `./start-linux.sh`.

Сайт откроется на http://localhost:3000.

# InvestStart

Учебный симулятор инвестиций: котировки и новости в реальном времени, торговый терминал для демо-сделок и AI-советник.

## Запуск

1. Установите Node.js 18 или новее (nodejs.org).
2. Скопируйте `.env.example` в `.env` и при желании впишите `AI_API_KEY`.
3. Выполните `npm start` и откройте http://localhost:3000

Устанавливать пакеты не нужно: сервер написан без внешних зависимостей.

## Что нового в этой версии

- **Обновление в реальном времени (SSE):** котировки, новости и стоимость портфеля обновляются автоматически без перезагрузки страницы через `/api/stream`.
- **Торговый терминал:** вкладка «Терминал» в личном кабинете позволяет покупать и продавать активы в демо-режиме по рыночным котировкам с автоматическим пересчётом свободных рублей и истории сделок.
- **Светлый минималистичный дизайн:** интерфейс оформлен в стиле Apple / Notion.
